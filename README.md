Form2 - форма первого задания, в котором вам необходимо угадать случайное число.
В текстовое поле вводим число и нажимаем кнопку угадать, если вы ввели верное число то после нажатия кнопки сверху текстового поля появится сообщение.
Если нет то вы увидите подсказку
